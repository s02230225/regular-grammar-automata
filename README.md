# Регулярная грамматика и конечные автоматы

**Haskell · НКА · ДКА**

Консольный преобразователь право- и леволинейных грамматик в недетерминированный конечный автомат с последующей детерминизацией методом подмножеств. Программа выводит стартовое и допускающие состояния и список переходов.

```bash
printf 'S=aA|aB;A=b;B=c
' | stack run
stack test
```

Формат правила — `S=aA|b`, правила разделяются точкой с запятой. Стартовый символ берётся из первого правила. Повторные определения одного нетерминала объединяются. Для леволинейных правил используется форма `S=Ab|c`. Пустые цепочки не входят в формат; смешивание левых и правых правил и ссылки на неопределённые нетерминалы отклоняются.

Основные модули: `Grammar`, `Automaton`, `Convert`, `Determinize`. `test/Spec.hs` сравнивает распознавание НКА и ДКА на небольших языках. Для сборки нужен Haskell Stack с версией GHC из `stack.yaml`.
